# CanteenFreeRTOS

基于 STM32F103C8T6 + FreeRTOS 的食堂环境安全感知平台 V2.0。

## 项目简介

本项目在 V1.0 裸机实现的基础上，使用 FreeRTOS 重构软件架构，实现食堂大厅的客流监测、火灾/烟雾预警与远程状态查看。终端通过 ESP01S(WiFi) 接入 MQTT，接收云端 YOLOv5 人数检测与 LSTM 客流预测结果，驱动 OLED、三色 LED 与蜂鸣器；同时把本地 MQ2 烟雾、火焰、DHT22 温湿度数据定时上传至云端，并配套微信小程序展示实时状态。

## 硬件平台

- MCU：STM32F103C8T6
- 通信：ESP01S(ESP8266)
- 显示：I2C OLED(0.96', SSD1306)
- 传感器：MQ2 烟雾、火焰传感器、DHT22 温湿度
- 执行器：三色 LED(绿/黄/红)、有源蜂鸣器
- 按键：PB1(翻页)、PB11(消音)

## 软件架构

FreeRTOS 五任务模型：

| 任务 | 栈空间 | 优先级 | 职责 |
|---|---|---|---|
| Key_Task | 128B | 1 | 按键扫描与翻页/消音 |
| Display_Task | 256B | 2 | OLED 双页显示刷新 |
| Sensor_Task | 256B | 3 | MQ2/火焰/DHT22 采集 |
| UART_Task | 256B | 4 | ESP01S 串口通信与帧解析 |
| Alarm_Task | 128B | 5 | 火灾/拥挤/故障状态机与声光报警 |

任务间使用互斥量、二值信号量、事件组、任务通知与软件定时器进行同步。

## 核心技术

- **串口通信**：USART1 DMA + IDLE 中断接收不定长数据帧，自定义分隔符协议解析
- **任务同步**：互斥量保护共享数据，事件组驱动显示刷新，软件定时器判定云端离线
- **可靠性**：独立看门狗(IWDG)超时保护，火灾/拥挤/系统故障/正常四态状态机
- **协议**：MQTT 发布/订阅，下行帧 `$COUNT:n|PREDICT:a,b,c|THRESH:n|TIME:...#`

## 数据链路

摄像头 → YOLOv5 数人 → LSTM 预测 → Flask 后端
│
ESP01S ← MQTT (下行) ───────┘
│
STM32 (显示/报警/传感器采集)
│
MQTT (上行) → Flask → 微信小程序
